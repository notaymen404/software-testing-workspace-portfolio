# Jira Workflow & Test Management

This document outlines my experience managing software testing tasks, tracking bugs, and using Kanban workflows.

## 1. Core Kanban Workflow
- **To Do:** Tasks, user stories, and bug tickets waiting to be picked up.
- **In Progress:** Active work being handled (such as writing tests or fixing code).
- **In Review:** Verification phase where QA checks the implementation and validates fixes.
- **Done:** Fully tested, verified, and approved tasks.

## 2. Example Feature Ticket & Subtask Breakdown
Here is an example of a parent task (`KAN-4`) created for testing login functionality, broken down into granular subtasks:

* **Parent Task:** Test User Login Functionality (`KAN-4`)
* **Subtasks:**
  * `KAN-5`: Test login with valid username and password credentials.
  * `KAN-6`: Test login with invalid username and password credentials (verify error message appears).
  * `KAN-7`: Test login with empty boxes (error message appears).
  * `KAN-8`: Test "forgot password" recovery link.
